## 이 방식의 한계 — 알고 시작할 것

- **GitHub Pages 사이트는 «공개»다.** 저장소를 Private으로 해도 사이트는 로그인 없이 열린다. 접근 제어가 되는 Pages는 GitHub Enterprise Cloud 플랜에만 있다.
- **저장소 내용도 공개다.** Public 저장소면 Pages 주소뿐 아니라 저장소에서도 HTML을 내려받을 수 있다.
- **이 HTML은 자체 완결형이라 `Ctrl+S` 한 번으로 완전한 사본이 만들어진다.** 어떤 방법도 「최초 접근」만 통제한다.
- 판매 배포에서 결제 검증이 필요해지면 **사내 회원 시스템에 얹거나**, Cloudflare Pages Functions로 발급 코드를 검증하는 구조로 옮겨야 한다. (Cloudflare **Access** 는 무료 50석 · 초과 시 1인당 과금이라 학생 판매에 맞지 않는다.)

## 왜 `exam-qa` 를 직접 올리지 않는가

1. 🔴 `원천자료/파워하우스 기출문제 2022.pdf` 가 **125.2 MB** 로 GitHub의 **개별 파일 100MB 하드 제한**을 넘는다. 이미 커밋 이력에 있어 push 자체가 거부된다. 우회하려면 전 커밋 재작성(`git lfs migrate`)이 필요한데, 세 트랙이 공유하는 워킹트리에서 **해서는 안 되는 작업**이다.
2. `exam-qa` 의 `.git` 이 이미 **479MB** 다. 4.5MB 산출물을 재배포마다 커밋하면 계속 불어난다.
3. `exam-qa/.gitignore` 10줄이 `dist/` 를 무시한다 — 산출물을 소스에 넣지 않는 것이 원래 설계다.

## 최초 1회 — GitHub 연결

1. GitHub 웹에서 **빈 저장소**를 만든다. README·라이선스·gitignore **전부 체크 해제**.
2. 아래를 실행한다(`<계정>`·`<저장소>` 를 바꾼다).

```
cd /c/Users/jbseo/Desktop/exam-dist-2022
git remote add origin https://github.com/<계정>/<저장소>.git
git push -u origin main
```

🔴 **토큰을 URL에 넣지 말 것**(`https://사용자:토큰@github.com/...`). `.git/config` 에 평문으로 남는다.
Git for Windows에 포함된 **Git Credential Manager** 가 브라우저 로그인 창을 띄우니 그걸 쓴다.

3. 저장소 → **Settings → Pages** → *Source* **Deploy from a branch** → Branch **main** / **`/ (root)`** → Save
4. 같은 화면에서 **Enforce HTTPS** 를 켠다.
5. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 에서 열린다.

## 파일 설명

| 파일 | 왜 있나 |
|---|---|
| `index.html` | 해설집 본체. **파일명이 `index.html` 이라 폴더 URL만으로 열린다.** 원래 이름(`2022_편입영어_해설.html`)은 URL 인코딩 시 65자가 되어 공유가 어렵다 |
| `.nojekyll` | Pages가 기본으로 Jekyll을 돌려 **`_` 로 시작하는 파일·폴더를 무시**한다. 나중에 `_html/` 같은 걸 함께 올려도 사라지지 않게 막는다 |
| `robots.txt` | 검색엔진 색인 차단. 판매본이 검색에 뜨지 않게 한다. 다만 **신사협정**이라 강제력은 없다 |
| `배포.sh` | 블로커 실측 → 복사 → 해시 대조 → 커밋 → push |

### 참고 — 이 HTML의 성질

- **외부 의존 0** (`http` 1회는 SVG 네임스페이스라 네트워크 요청이 아니다). 어떤 정적 호스팅에서도, 오프라인에서도 그대로 동작한다.
- 🔴 **한 줄이 2,796,873자**(파일의 99%. JSON payload). HTML로 «렌더»하면 문제없지만, **텍스트로 «미리보기»하려는 도구는 멈춘다.**
  구글 드라이브가 얼어붙은 원인이 이것이다(드라이브는 HTML을 렌더하지 않고 텍스트로 보여주려 한다. 드라이브 웹호스팅은 2016년 폐지됐다).
  파일로 전달해야 한다면 **ZIP으로 감쌀 것** — 미리보기를 시도하지 않고, 4.53MB → 1.05MB(23%)로 줄어든다.
